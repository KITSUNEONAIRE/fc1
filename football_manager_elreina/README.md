# Football Manager: Elreina Edition

Глубокий футбольный менеджер-симулятор с процедурной генерацией мира, лиц, гербов и флагов.

## 🎮 Особенности

### Процедурная генерация
- **16 регионов** с уникальными характеристиками
- **40+ городов** на интерактивной карте
- **7 политических партий** с флагами и идеологиями
- **5 этнических групп** с уникальными палитрами
- **Тысячи игроков** с пиксельными портретами
- **240 комбинаций гербов** для клубов

### Ключевые механики
- ⭐ Двойная экономика (Деньги + Очки Престижа)
- 🏛️ Политическая система с выборами
- 👮 Фанатские столкновения
- 🏥 Медицинская система с 15+ типами травм
- 🤝 Дипломатия клуб-государство
- 📰 Медиа и пресс-конференции
- 🗺️ Интерактивная карта Эльрейна

### Визуальный стиль
- Пиксельные портреты (32×32) с масштабированием
- Современный UI в тёмных тонах
- Цветовая палитра: #080C14 (фон), #1E90FF (акцент)

## 🚀 Запуск

1. Откройте проект в Godot 4.2+
2. Запустите сцену `scenes/main_menu/MainMenu.tscn`

## 📁 Структура проекта

```
football_manager_elreina/
├── autoloads/           # Глобальные скрипты
│   ├── GameState.gd     # Управление состоянием игры
│   ├── WorldGenerator.gd # Процедурная генерация
│   ├── TimeSystem.gd    # Система времени
│   └── EventManager.gd  # События и уведомления
├── scenes/              # Сцены
│   ├── main_menu/       # Главное меню
│   ├── dashboard/       # Основная панель
│   ├── map/             # Карта мира
│   ├── team/            # Команда
│   ├── finances/        # Финансы
│   └── ...
├── scripts/             # Утилиты и данные
├── assets/              # Ресурсы
└── project.godot        # Проект Godot
```

## 🎯 Геймплейный цикл

1. Создание менеджера и команды
2. Еженедельное управление:
   - Тренировки
   - Матчи
   - Трансферы
   - Финансы
   - Политика
3. Конец сезона - награды и переход в новый сезон

## 📊 Системы

- **WorldGenerator**: Генерация карты, регионов, городов, команд, игроков
- **GameState**: Сохранения, прогресс, отношения
- **TimeSystem**: Время, недели, сезоны
- **EventManager**: Случайные события, инциденты
