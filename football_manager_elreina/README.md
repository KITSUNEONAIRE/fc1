# Football Manager: Elreina Edition ⚽

**Глубокий футбольный менеджер-симулятор с процедурной генерацией мира**

---

## 🎮 О ПРОЕКТЕ

Football Manager: Elreina Edition — это масштабный симулятор управления футбольным клубом в вымышленной стране Эльрейн (1997 год). Каждая новая игра создаёт уникальный мир с 16 регионами, 40+ городами, тысячами игроков с пиксельными портретами и сотнями клубов с уникальными гербами.

---

## ✅ РЕАЛИЗОВАННЫЕ МЕХАНИКИ

### 🌍 Процедурная генерация мира
- **16 регионов** с полигонами, климатом, этническими группами
- **40+ городов** с координатами на карте
- **7 политических партий** с цветами, иконками, идеологиями
- **Команды** с процедурными гербами (5 форм × 6 эмблем × 8 цветов = 240 комбинаций)
- **Игроки** с навыками, позициями, контрактами, этнической принадлежностью
- **Свободные агенты** (50-100 игроков без клуба)
- **5 этнических групп** с уникальными палитрами для портретов

### 🏛️ Политическая система
- National Front, Democratic Union, Labour Party, Green Alliance, Conservative Party, Regional Development, Trade Party
- Система напряжённости регионов (0-100)
- Пульсация на карте при высокой напряжённости
- Выборы каждые 3 года (президентские) и 1.5 года (парламентские)

### 💰 Двойная экономика
- Деньги (£) и Очки Престижа (PP)
- Система отношений (совет директоров, фанаты, медиа, государство)
- Банковская система (кредиты, депозиты)
- Магазин улучшений за PP

### ⏱️ Система времени
- Начало: 1 августа 1997 года
- 38 недель в сезоне
- Учёт високосных лет
- Ускорение времени (x1, x2, x5)

### 📊 Игровые системы
- **Team** — управление составом, карточки игроков
- **Tactics** — 5 формаций (4-4-2, 4-3-3, 3-5-2, 4-2-3-1, 5-3-2), стили игры
- **Transfers** — трансферный рынок, свободные агенты, покупка/продажа
- **Finances** — доходы, расходы, спонсоры, инвестиции
- **Politics** — политическая карта, партии, выборы
- **Fans** — фанатские группы, столкновения, безопасность
- **Medical** — травмы (15+ типов), лечение, медицинский персонал
- **Press** — СМИ, новости, пресс-конференции
- **Shop** — магазин улучшений за Prestige Points
- **Map** — интерактивная карта регионов

### 🎨 Визуальный стиль
- Цветовая схема: #080C14 (фон), #1A2633 (панели), #1E90FF (акцент)
- Современный UI с тёмной темой
- Интерактивная карта с политическим кодированием
- Поддержка разрешений: 1280×720, 1920×1080, 2560×1440

## 🚀 КАК ЗАПУСТИТЬ

### Требования
- **Godot Engine 4.2+** (https://godotengine.org/download)
- OS: Windows 10/11, Linux, macOS 10.15+
- RAM: 2 GB минимум, 4 GB рекомендовано
- Storage: 200 MB свободного места

### Установка
1. Скачайте и установите Godot Engine 4.2+
2. Клонируйте или скачайте этот проект
3. Откройте Godot → Import → Выберите `project.godot`
4. Запустите сцену `scenes/main_menu/MainMenu.tscn`

### Управление
- **ЛКМ** — навигация по интерфейсу
- **Навигационная панель** — переключение между разделами
- **Advance Week** — переход к следующей неделе

## 🔧 ТЕХНИЧЕСКИЕ ДЕТАЛИ

### Godot 4.2 Совместимость
✅ `config_version=5`  
✅ Синтаксис GDScript 2.0  
✅ Типизированные переменные (`var name: Type = value`)  
✅ Аннотации `@onready`  
✅ Новая система Layout Mode (1, 2, 3)  
✅ Современный синтаксис сигналов  

### Архитектура
- **Autoload Singleton Pattern** — глобальное состояние игры
- **MVC-like подход** — разделение логики и представления
- **Signal-based communication** — слабая связанность компонентов
- **Procedural Generation** — детерминированная генерация через seed

### Системы сохранения
- JSON формат
- 6 слотов сохранений (5 ручных + автосохранение)
- Полное сохранение состояния игры
